# 🎄 Christmas Gift Card Website

A beautiful, decorated holiday-themed gift card website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- ✨ Beautiful holiday-themed UI with Christmas decorations
- ❄️ Animated snowflakes falling effect
- 🎁 Interactive gift card creation form
- 🖨️ Print-ready gift card preview
- 🎨 Festive colors and animations
- 📱 Responsive design

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
npm run build
npm start
```

## Technologies Used

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- CSS Animations
